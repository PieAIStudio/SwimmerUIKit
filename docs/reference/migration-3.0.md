# 升级到 UIKit 3.0

本页对应3.0.0-rc.1起的3.0系列主动升级，不是发布成功公告。稳定版为3.0.0（与3.0.0-rc.3源码相同，见下文）；3.0.0-rc.1与rc.3已发布到npm next。发布到latest前，稳定latest仍是2.14.0；以npm标签回读和当前工作记录为准。产品保持原有精确版本时不受影响。
不保留兼容层；先迁移源码和样式，再升级产品依赖。本仓库不替产品改代码。

3.0.0-rc.2 修正原生按钮属性转发：ComponentProps<'button'> 可传给 GameButton / GameIconButton，显式提供 children、游戏含义与 ref。无需在应用侧丢弃 React 的 rel 元数据或用类型断言绕过；只有 href 才生成链接，target / download 仍不能单独附在按钮上。已有页面不需要改变外观或液体配置。

3.0.0-rc.3 调整按压与处理中反馈，公开名字不变，产品代码不需要改。CTA 与平面水滴的按压更深，快速点按也至少保持 140 毫秒后再回弹；Space / Enter 与指针一样遵守这一最短保持。GameButton 新增可选 `pending`：主按钮保持液体 CTA 并缓慢呼吸，其余变体轻微脉冲，都设置 aria-busy 而不禁用，点击仍交给产品守卫。减少动态时保持静止。LiquidSurface 另有一个可选的 breathing，供高级用法；GameButton 使用者无需处理。已有页面的截图或视觉回归会看到更明显的按压形变，需要按新值重新确认。

3.0.0 是 3.0.0-rc.3 源码的稳定版：只改版本号，公开名字、参数、样式和迁移表与 rc.3 相同。产品主动升级时精确安装 `@pieai/swimmer-ui-kit@3.0.0`；若依赖仍是 rc 版本，把它改为 3.0.0 并重新运行产品门禁。产品不会因 npm 标签变化而自动升级，仍以各自锁定的精确版本为准。

## 参数、主题与样式

| 旧用法 | 新用法与边界 |
| --- | --- |
| `data-game-ui-theme="night"` | 改成 `data-game-ui-theme="dark"`；明暗目标值为 light / dark。选择器、dataset 赋值、主题判断、closest 查询一起改。旧值只由检查工具报错，不再支持。 |
| `--game-ui-glass-night`、`--game-ui-glass-night-soft` | 分别改成 `--game-ui-glass-dark`、`--game-ui-glass-dark-soft`；数值不变，统一深色命名。 |
| `LiquidGroup.Item effect="melt" / effect="bend" / dissolve` | 从 `./liquid-effects` 导入 `LiquidEffectsGroup`，将相互作用的整组及子项改用它；参数语义和资源预算不变。根入口的 LiquidGroup.Item 不再接受这些参数。 |
| `liquidFormItem('drain').dissolve` | drain 只提供动作，不再自动附加图像溶解。实际需要图像接触溶解时，显式使用可选特效入口的 `LiquidEffectsGroup.Item dissolve`。 |
| `--game-ui-liquid-metal-*` | 随零使用的金属按钮删除；不存在替代 WebGL 皮肤，也不存在兼容 token。 |
