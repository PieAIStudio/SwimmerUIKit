# DropletSurface

普通控件共用的二维水滴轮廓：平滑路径加填色/细边，不使用液体滤镜。原生父控件始终拥有点击、焦点和值，只有背景轮廓按压变形。

尺寸变化时测量一次；按压使用欠阻尼弹簧，静止时没有动画循环。减少动态或 static 时不形变；卸载后清理观察器和帧回调。

SVG 视口始终贴合原生命中框；绘制留白只放在 viewBox 坐标，真实波动路径保持可见，不放大 SVG 布局框。否则字体替换后的 5px 收窄会让旧装饰留白产生 dialog 横向滚动（410 > 408）。回归在 ResizeObserver 下一次通知前检查这个场景。

配色只读取语义 token。七套风格和明暗在 tokens/control-styles.css，不在本组件分支。不要用它画液体 CTA、输入内容或产品状态。
