# GameHelpCard

悬停、键盘焦点或触摸时打开的小卡片：一个标题、一到三行正文，可选一段循环的短演示，可选一个“完整指南”链接。它是帮助的第二级，比 GameTooltip 多一点内容，但仍可省略。

主要参数：`children`（单个可聚焦触发器）、`label`（卡片的可访问名称）、`topics`（一到四个主题，多于一个时显示页签）、`link`、`placement`、`align`、`openDelay`；[完整参数](GameHelpCard.tsx)以源码为准。

行为：鼠标悬停经过 `openDelay` 后打开，指针可移入卡片切换页签或点击链接，离开约 150 毫秒后关闭。键盘聚焦触发器会打开卡片但不抢焦点，Tab 进入卡片，Escape 关闭并回到触发器。触摸的第一次点按只打开卡片，第二次点按才执行触发器的动作；点击卡片外关闭。

媒体只在卡片第一次打开、并且所在主题被选中时才请求；视频静音、循环，只在可见时播放。系统要求减少动态时不自动播放，显示 `poster`。`alt` 是媒体的可访问文字。

边界：必要信息、错误和价格不能只藏在这里；需要填写或点击的内容不要放进卡片。
